# 사유의 방

정원과 연결하지 않는 독립 명상 공간이다. 정원 입구, 방 서버, 접속 상태, 저장 자료를 공유하지 않는다. 이 폴더의 index.html이 독립 사이트의 첫 화면이다.

## 별도 Cloudflare 프로젝트 설정

- 프로젝트/Worker 이름: `sayu-room`
- 저장소: 현재 저장소, main
- 루트 디렉터리: `sayu-room`
- 빌드 명령: 없음 (정적 HTML)
- 정적 자산 디렉터리: `.`
- Wrangler를 사용하는 경우 이 폴더의 `wrangler.toml`을 지정한다.

저장소 루트의 정원 배포 설정과 자동 배포 연결은 변경하지 않는다. 실제 독립 주소는 별도 프로젝트를 배포한 뒤 확정한다. 기존 정원 주소의 `/sayu-room/`은 이 독립 사이트의 주소가 아니다.

불상 출처와 이용조건: `models/SOURCES.md`. 내장 무압축 GLB 전용 로더는 이 두 모델의 패킹 구조만 지원한다. 새로운 GLB로 교체할 때 구조 검증이 필요하다.
