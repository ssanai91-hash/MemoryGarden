# 사유의 방 — 인수인계 (v0.1)

작성: 클로드 / 승인: 사령관(형) / 2026-11-04
협업: 형 = 최종 결정 / 클로드 = 3D 구현 / GPT = 기획·연출 아이디어·검토

## 무엇인가

국립중앙박물관 '사유의 방'의 분위기를 참고한 온라인 명상 공간.
어두운 원형 방, 별처럼 반짝이는 천장, 위로 갈수록 따뜻하게 밝아지는 곡면 벽, 낮은 원형 단 위의 반가사유상 두 점.
들어가서 절하고, 명상하고, 고요히 머무는 것이 목적.

- 파일: `sayu-room/index.html` 한 장 (Three.js r128, cdnjs에서 로드)
- 기억의 정원 본체(`index.html`)와는 아직 연결하지 않은 독립 페이지

## 원칙

- 공간은 박물관 전시실을 1:1 복제하지 않는다. 전시실은 현대 건축가의 설계 작품이므로 분위기 요소(어둠, 별빛 천장, 벽 상단 조명, 원형 단, 두 불상)만 살린 우리 버전으로 만든다.
- 블로그·SNS 사진은 촬영자 저작물이므로 텍스처나 배경으로 쓰지 않는다.
- 반가사유상 자체는 유물이라 형상 재현은 문제없음. 실제 스캔 데이터를 쓸 때는 박물관 이용조건(공공누리 유형)을 확인한다.

## GPT에게 부탁하는 검토

- 입장 연출(입구 → 걸어 들어가는 6.5초)이 충분히 고요한지, 더 길거나 짧아야 하는지
- 명상 중 화면 문구('들이쉬고/내쉬고') 대신 더 나은 안내 방식
- 절하기 동작 시간 배분(숙이기 1.5초 → 엎드림 1.8초 → 머무름 1.5초 → 일어나기 3초)
- 추가하면 좋을 의식: 향 피우기, 촛불, 소원 남기기 등 — 그리기 전에 제안으로 먼저 올려줄 것
