# 개인 입장 코드와 수행 기록 · 후광

개인 코드와 수행 기록, 후광 보상의 구현 및 검증 내역이다. Cloudflare 직접 배포는 별도 작업이다.

## 입장과 개인 기록

- 처음 입장 시 암호학적 난수로 개인 코드 20자리(4자리씩 5묶음)를 한 번 만든다. 등록 도중 새로고침해도 같은 코드를 재시도한다.
- 메뉴의 `내 입장 코드`에서 코드 확인·명시적 복사·다른 코드로 전환을 제공한다. 다른 기기에서는 기존 코드만 입력하면 이름·캐릭터·반려동물과 기록을 불러온다.
- 같은 기기는 코드와 마지막 프로필을 보관해 자동 입장한다. `나가기`는 현재 접속과 수행만 종료하며 개인 기록을 지우지 않는다. 같은 탭의 명시적 나가기 화면은 기존 동작을 유지한다.
- 코드는 본인 인증 수단이다. 서버에는 코드 원문 대신 SHA-256 검증값을 저장하고, 공개 접속 식별자는 별도 해시로 파생한다. 코드·검증값·접속 세대 값은 다른 방문자에게 보내지 않는다. 초대 URL은 기존 고정 주소 그대로 사용한다.
- 영구 기록은 `person.<공개 식별자>` 레코드로 보관한다. 24시간 방문 보관 기간이나 48시간 수행 작업 정리와 분리하며, 기록에 자동 만료를 두지 않는다.
- 108/3000의 진행 횟수, 총 수행 횟수, 각각의 완료 횟수, 획득한 최고 후광 단계, 각 후광 종료 시각을 별도 보관한다. 진행 횟수 초기화는 누적·완료·획득 이력을 지우지 않는다.
- 절 진행은 서버 시간으로 계산하며 클라이언트가 보낸 횟수나 후광으로 개인 보상을 올릴 수 없다. 일시 단절 중 서버에서 이미 시작한 수행은 계속 계산한다. 시작 전 연결이 끊긴 경우에는 요청을 보관하고 연결 후 시작한다.
- 같은 코드로 다른 기기에 입장하면 최신 기기가 이어받는다. 이전 접속의 지연된 명령이나 외형 저장이 최신 기록을 덮지 않도록 서버의 접속 세대를 확인한다. 이름이 같아도 코드가 다르면 다른 사람이다.
- 기기 캐시의 절 기록도 개인 코드별로 분리한다. 처음 코드로 전환할 때는 기존 탭 토큰에 연결된 서버 저장 수행을 한 번만 이전한다. 서버 기록이 없는 과거 로컬 숫자나 이미 초기화한 과거 총횟수까지 복원하지는 않는다.

## 후광 효과와 실제 유지 시간

| 완료 | 효과 | 완료 순간부터 현실 시간 |
| --- | --- | --- |
| 108배 | 머리 위 작은 흰색 고리 | 72시간(3일) |
| 3000배 | 머리 위 빨간 고리와 몸 발광 | 168시간(7일) |

- 두 후광의 종료 시각을 독립 보관한다. 둘 다 유효하면 빨간색을 우선한다. 빨간색이 끝나고 흰색 시간이 남아 있으면 흰색으로 돌아간다.
- 실제 완료 시각에서 종료 시각을 계산한다. 앱 전환·재입장·기기 변경·서버 재시작·뒤늦은 완료 확인으로 시간이 새로 시작하지 않는다. 같은 완료 요청 재전송은 중복 보상하지 않는다.
- 후광은 실제 머리 좌표 위에 수평으로 놓는다. 기존 3D 캐릭터·스프라이트·절하기·앉기·눕기에서 머리 위치를 따른다.
- 빨간 몸 발광은 본인 메시/스프라이트에만 별도 가산 패스를 더한다. 공유 원본 재질을 바꾸지 않으며 새로운 점광원을 추가하지 않는다. 효과 종료나 캐릭터 교체 때 발광 패스를 숨기거나 해제한다.
- 초의 24시간 수명은 바꾸지 않는다. 사유의 방은 변경하지 않는다.

## 검증과 반영

`npm test`는 실제 서버 핸드셰이크·저장 트랜잭션·기기 이동·장기 재입장·누적·재전송·초기화·분리된 코드 캐시를 검사한다. `node tests/bow-halo-world.mjs <three-r170.mjs>`는 실제 Three.js에서 머리 위 위치·흰/빨간색·몸 발광·재질 격리·만료·자원 해제를 검사한다.

실제 브라우저 화면과 휴대폰 발열/프레임은 사용자 확인 범위다. 반영하려면 서버와 정적 파일을 함께 업데이트해야 한다. 기존 서버에는 새 코드 입장을 허용하지 않는 호환 안내를 넣었다.
