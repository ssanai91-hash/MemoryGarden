# 사진 기반 검은 푸들

기억의 정원 반려동물 선택에서 **강아지 → 푸들 → 블랙**을 고르면 사진의 특징을 참고한 입체 모델이 표시된다. 이미 그 조합을 저장한 사용자는 자동 적용된다. 다른 품종과 털색 및 사유의 방은 변경하지 않는다.

`assets/black-poodle.js`는 실제 메시로 몸·머리·처진 귀·곱슬털·눈·코·혀·은색 체인과 주황색 인식표를 구성한다. 사진 자체나 생성 시안을 평면으로 붙이지 않는다. 단일 정면 사진을 참고해 수작업으로 근사한 모델이며, 생성 시안의 모든 형태와 털 표현을 그대로 복원한 모델은 아니다. 보이지 않는 측면과 뒷면은 근사했다.

기존 `makeDog` / `updateDog`의 따라 걷기·다리·머리·꼬리 동작과 쉬는 자세를 사용한다. 선택 및 저장과 서버 전송은 기존 `{b:3,coat:2,n:...}` 형식을 유지해 새 서버 프로토콜 없이 친구에게도 동일하게 표시한다. 변경하려면 메뉴의 **반려동물 변경**을 연다.

모든 검은 푸들이 지오메트리와 재질을 공유한다. 곱슬털은 부위별로 병합해 털 한 가닥마다 그리기 호출이 발생하지 않는다. 카메라 거리 7m 미만은 정밀, 7~19m는 중간, 19m 이상은 단순 형상으로 전환한다(전환 흔들림 방지 12%). 정원 기본 시점에서도 중간 단계 털을 유지한다. 동적 그림자는 기존 정원의 반려동물 규칙을 따른다. 외부 모델·텍스처 다운로드는 없다.

정적 자산 배포에 필요한 `.assetsignore` 허용 항목을 추가했다. Cloudflare 수동 배포 및 실제 기기 화면 확인은 수행하지 않았다.

검증: `node tests/black-poodle.mjs /absolute/path/three-r170.mjs`. 실제 r170에서 메시·지면 높이·LOD·공유 자원·교체 시 자원 보존·서버 프로필 호환을 확인한다.
