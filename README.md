# 기억의 정원 · MemoryGarden

좌불상 앞에서 기도하거나 108배를 하고, 강아지·고양이와 산책하는 3D 웹 정원입니다.

## 24분 정원 하루 · 이동하는 해와 달 · 긴 비 · 반달 보완 (2026-11-02)

- 1차 담당 범위만 구현했습니다. 하루 길이는 `GARDEN_DAY_MINUTES=24` 한 값으로 조절하고, 공통 `gardenHour()`를 전역에도 공개합니다. 밤 11분(19:30~06:30), 새벽 2분, 낮 8분, 노을 3분입니다. 고정 밤 강제를 제거했으며, 서버 보정 시각을 기준으로 입장/복귀와 관계없이 시간이 흐릅니다.
- 하늘·구름·안개·주변광이 부드럽게 변하고 태양 원반과 달이 하늘을 이동합니다. 기존 그림자 방향광 하나를 해/달에 재사용합니다. 한밤의 달 위상은 고정하고 정원 날짜에 따라 순서대로 바뀝니다.
- 날씨는 하루 시계와 독립적입니다. 30분 날씨 창마다 최대 한 차례의 강수 전선이 낮은 점유율로 지나가며, 실제 비는 3~6분 지속되고 25~40초에 걸쳐 차오르고 잦아듭니다. 구름은 비보다 먼저 모이고 늦게 걷히며 비와 눈은 자동으로 섞이지 않습니다. 수동 날씨 전환 시각을 서버에 함께 보관해 늦은 접속에도 같은 전환을 적용합니다.
- 달 표면은 재사용하는 512px 한 장으로 줄이고 밉맵을 끕니다. 어두운 쪽은 약 0.6% 알파의 희미한 표현만 남기며 가산 합성으로 별을 검게 가리지 않습니다. 원본 사진은 유지합니다. 휴대폰에서 보고된 바둑판 현상의 실제 원인은 기기에서 확인하지 못했습니다.
- 반딧불이·새소리·밤 풀벌레·농막 창문/처마 전구·폭포 푸른빛 연결은 다음 담당자 범위로 남겼습니다. 음악과 고목 모델은 변경하지 않았습니다. 현재 main에서 이미 제거된 Yoiyami를 이번에 복원하지 않습니다.
- 다음 담당자는 [GARDEN_TIME_HANDOFF.md](GARDEN_TIME_HANDOFF.md)의 공통 함수와 시간대 표를 사용하면 됩니다. 화면과 Worker를 같은 소스로 반영해야 합니다. 로직 검사 3개와 클라이언트/Worker 문법·공백 검사를 통과했습니다. 실제 브라우저·휴대폰 화면·성능 검증과 Cloudflare 직접 배포는 하지 않았습니다.

## 1안 달빛 벚꽃 성소 구현 (2026-11-02)

- 사용자가 고른 `달빛 벚꽃 성소` 시안을 기존 3D 정원에 옮겼습니다. 모닥불 왼쪽에 높이 약 23m의 고목, 호숫가 농막 너머에 약 17m의 고목을 배치합니다. 굵게 휘어진 줄기와 감긴 보조 줄기, 옆으로 뻗은 가지, 지면을 따라 퍼진 뿌리를 곡선/테이퍼 도형으로 만듭니다. 단순히 기존 나무를 크게 늘린 모델이 아닙니다.
- ImageGen으로 만든 옅은 수피와 분홍/흰 꽃송이를 웹용 텍스처로 내보내고 정적 자산 허용 목록에 포함했습니다. 텍스처는 두 고목에서 공유하고 꽃가지는 투명 경계가 있는 교차 면과 열린 잎가지로 구성합니다. 수관을 둥근 공으로 채우지 않습니다. 꽃 텍스처 로딩 실패 시 사각 면은 숨기고 잎가지 표현을 유지합니다.
- 연보라 꽃줄기와 작은 빛나는 꽃송이가 가지 아래로 늘어집니다. 뿌리 주변에는 이끼와 은은한 빛을 더하며 추가 점광원/그림자 패스를 만들지 않습니다. 거목의 본체 충돌 영역을 추가하고 다른 나무는 뿌리 주변을 비웁니다.
- 고목 주변에는 벚꽃·흰꽃·목련·자작·은빛 잎나무가 더 자주 모이게 하고 산책 구역 나무 배치 상한을 290그루로 늘립니다. 나머지 수종의 다양한 윤곽은 유지합니다.
- 모닥불과 고목 주변 11개 꽃밭 구역에 분홍·흰색·연보라 꽃을 밀도 있게 심습니다. 작은 구체 꽃머리 대신 펼쳐진 꽃잎 도형을 사용하며, 기존 길·벤치·기도 공간·테이블·포차·호수/개울/데크·농막 출입 공간을 비웁니다.
- 240개의 꽃잎이 GPU에서 천천히 흩날립니다. 가까이 있는 정원에서만 보이고, 화면 품질 가볍게/균형/선명하게에 따라 72/144/240개로 조절합니다. 음악방과 밤하늘 집중 보기에서는 숨깁니다. 고목 그림자도 가벼운 품질에서는 끕니다.
- 시안의 분위기·색·주요 요소를 기존 산책 가능한 정원에 맞춰 옮기는 구현입니다. 시안과 동일한 지형·카메라·영화 수준 렌더링을 보장하는 것은 아닙니다. 기존 소리·공유 데이터·사용자 상태·서버 규칙은 변경하지 않습니다.
- 코드 대조·클라이언트 문법/공백 검사를 완료했습니다. 기존 요청에 따라 실제 브라우저 화면·휴대폰 성능/청음 검증 및 Cloudflare 직접 배포는 진행하지 않습니다. 사용자 화면 검증 전입니다.

## 둥근 수관 반복 제거 (2026-11-02)

- 이전 수목원 수정본도 여러 나무에 공통 구체를 쓰고 있어, 색과 크기를 바꿔도 비슷한 윤곽이 될 수 있었습니다. 나무 수관의 구체를 제거하고 잎사귀 다각형이 따로 보이는 가지 묶음으로 교체했습니다. 구체는 낮은 관목과 바위 등에만 남깁니다.
- 은행은 위로 벌어지는 가지와 부채꼴 잎, 단풍은 낮게 옆으로 뻗는 가지와 갈라진 잎, 자작은 흰 줄기와 성긴 잎, 목련은 큰 잎과 밝은 꽃, 벚나무는 갈라지는 가지 사이가 비어 있는 꽃가지로 구분합니다. 자엽 나무는 세로로 길고, 은빛 나무는 작은 잎으로 표현합니다.
- 소나무는 구름 같은 둥근 덩어리 대신 불규칙하고 얇은 가지층으로 구성합니다. 전나무의 원뿔층은 유지하고, 버드나무는 긴 타원 덩어리를 여러 가느다란 잎줄기로 바꿉니다. 버드나무는 윗부분보다 아래 끝이 더 흔들립니다.
- 원경과 낮은 상세도에서도 잎/부채/가지층/늘어진 잎줄기를 유지하고 구체로 대체하지 않습니다. 나무 잎은 형태별 공유 도형과 인스턴싱을 사용합니다. 실제 프레임 속도나 시각적 완성도는 측정하지 않았습니다.
- 문법 검사와 코드 대조를 완료했습니다. 2026-11-02 사용자의 명시적인 GitHub 반영 요청에 따라 앞선 음악·자연음·수목원 수정과 함께 main에 반영합니다. 브라우저 화면 검증·Cloudflare 직접 배포는 진행하지 않았습니다. 운영 화면 확인은 이 커밋의 소스로 수동 빌드한 뒤 진행해야 합니다.

## 다채로운 수목원 풍경 (2026-11-02)

- 초록색 둥근 수관 위주였던 나무를 12가지 색·수형으로 구성했습니다. 연분홍/흰 벚꽃, 백목련, 홍단풍, 황금 은행, 흰 줄기 자작나무, 수양버들, 느티나무, 자엽 너도밤나무, 은빛 잎나무, 푸른 전나무, 소나무를 참고한 그림책식 표현입니다. 실제 수목의 계절·생육을 재현하는 기능은 아닙니다.
- 각 나무마다 높이·폭·기울기·가지 방향·수관 덩어리·색 농담을 달리합니다. 자작나무의 흰 수피와 어두운 띠, 버드나무의 늘어진 가지, 전나무의 층진 원뿔, 소나무의 옆으로 퍼진 가지, 목련/벚나무의 밝은 꽃을 구분했습니다.
- 최대 235그루의 산책 구역 나무를 고정 난수로 배치합니다. 분홍/흰 꽃나무 숲, 단풍/황금빛 숲, 은빛/침엽수 숲처럼 느슨한 군락을 만들고 주변에 다른 수종을 섞습니다. 물가에는 버드나무와 자작나무를 우선합니다. 입구 쪽에는 비교적 작은 꽃나무, 뒤쪽에는 높낮이가 다른 숲이 이어집니다. 먼 숲도 색·높이·수관 형태를 섞었습니다.
- 중앙 진입 시야, 두 순환 산책길과 세 연결길, 호수 데크·개울·폭포·농막·불상/성모상·포차/게시판·테이블·벤치 접근 공간을 비웁니다. 나무끼리도 최소 간격을 두며, 줄기의 위치와 굵기에 맞춰 충돌 범위를 만듭니다. 연결 산책길의 풀·꽃도 제거해 길이 드러나도록 했습니다.
- 낮은 관목과 분홍·연보라·크림색 작은 꽃이 나무 사이를 잇습니다. 밤에는 나뭇잎 고유색에 약한 보정만 더해 색을 구분하고, 버드나무는 별도 바람 움직임을 사용합니다. 나무 개별 오브젝트 대신 형태별 인스턴싱·공간 분할·거리별 도형 단순화를 유지하며, 먼 거리에서 줄기 충돌 위치는 바꾸지 않습니다.
- 구현·코드 대조·클라이언트 문법 검사·공백 검사를 완료했습니다. 프로젝트 지침에 따라 브라우저/실제 휴대폰 화면 검증과 Cloudflare 직접 배포는 진행하지 않았습니다. 실제 숲의 밀도·시야·프레임 속도는 사용자 화면에서 확인해야 합니다. 기존 방문 상태·공유 데이터·서버 규칙은 변경하지 않습니다.

## 빗소리·천둥 다양화와 자동 배경음악 제거 (2026-11-02)

## 혼자 즐기기: 폭포 명상 · 평상 낮잠 · 반딧불이

- **폭포 명상**: 폭포 웅덩이 가까이(약 11m 안)에 서면 `폭포 명상` 버튼이 나옵니다. 누르면 폭포를 보고 앉고, 화면의 원이 4초 들숨·6초 날숨으로 커졌다 작아집니다. 시간과 누적 시간이 표시되고 5분이 되면 알려 줍니다. 움직이거나 `명상 마치기`로 끝납니다.
- **평상 낮잠**: 농막 처마 아래에서 `평상에서 낮잠`을 누르면 평상에 눕고 화면이 서서히 어두워집니다. 낮잠 동안에는 날씨와 상관없이 내 화면에서 함석지붕 빗소리와 낙숫물이 들립니다. `깨어나기`로 일어납니다.
- **반딧불이 잡기**: 호숫가, 개울가, 농막 텃밭에 반딧불이 40마리가 깜빡이며 떠다닙니다. 가까이 가면 `반딧불이 잡기 ✨` 버튼이 나오고, 잡은 수는 왼쪽 병 버튼에 표시되며 많을수록 병이 밝게 빛납니다. 병을 누르면 모두 놓아주고, 반딧불이가 사방으로 날아갑니다. 잡힌 자리에는 45초 뒤 새 반딧불이가 나타납니다.
- 명상·낮잠 누적 시간과 병 속 반딧불이 수는 이 기기의 브라우저(`garden.calm`)에 저장됩니다.

## 호수 · 폭포 · 농막

- **큰 호수**: 남동쪽 길을 따라가면 지름 약 28m의 호수가 나옵니다. 길은 나무 데크로 호수를 가로지르고(위로 걸을 수 있음), 연잎·연꽃·갈대·물가 돌이 있습니다. 불꽃놀이 발사대는 호수 서쪽 물가로 옮겼습니다.
- **폭포**: 데크를 건너 둘레길 너머로 조금 더 들어가면 이끼 낀 바위 절벽에서 물이 떨어지는 폭포와 물웅덩이, 물안개가 있습니다. 개울이 호수까지 흐르고 둘레길과 만나는 곳에 나무 징검다리가 놓여 있습니다.
- **농막**: 호수 동쪽 물가에 함석지붕 농막이 있습니다. 처마 아래 마루와 평상에 올라설 수 있고(평상에서 앉기), 장작더미·물뿌리개·화분·텃밭이 있습니다. 창문과 처마 전구에 불이 켜져 있습니다.
- **자연의 소리** (자연의 소리 켜기 상태에서, 모두 브라우저 합성): 폭포 물소리(가까울수록 큼), 개울 졸졸, 호숫가 잔물결, 빗소리, 농막 처마 아래에서는 함석지붕 빗방울 소리와 낙숫물, 농막·폭포·호숫가 근처 새소리. 농막 처마 아래에서는 지붕·낙숫물이, 폭포 근처에서는 폭포 물소리가 커집니다.
- 데크·마루·평상 높이는 `groundY()`로 계산해 사람과 반려동물이 올라섭니다.

## 캐릭터 모습

입장할 때 고른 성별에 맞춰 모습이 무작위로 정해지고, 동작 메뉴의 `모습 바꾸기 🎲`로 마음에 들 때까지 다시 뽑을 수 있습니다.

- 남자: 어깨가 조금 넓고 눈썹이 진함. 머리 모양 5가지(짧은머리·가르마·삐죽·짧게 친 머리·곱슬), 콧수염·턱수염(가끔), 모자(가끔)
- 여자: 어깨가 좁고 속눈썹·붉은 입술. 머리 모양 5가지(긴 생머리·단발·포니테일·양갈래·똥머리), 치마 또는 바지
- 공통: 안경 없음/동그란 금테/네모 뿔테/선글라스, 피부·머리색, 성별별 옷 색 팔레트
- 예전 모습 데이터는 처음 다시 입장할 때 새 모습으로 바뀝니다. 서버는 새 항목(st, gl, fh, sk)을 범위 검사 후 친구들에게 전달합니다.

## 정원 1.5배 확장과 그림책 느낌 보강

- 걸을 수 있는 범위를 반경 60m에서 90m로 넓혔습니다(지름 1.5배). 화면(`WORLD_R`)과 방 서버(`worker/src/index.js`의 `WORLD_R`)를 같은 값으로 둡니다.
- 새로 넓어진 땅: 반경 57m 바깥 산책로와 안쪽 원형 길을 잇는 오솔길 3개, 네 곳의 꽃밭, 나무 320그루·덤불·바위를 더했습니다. 침엽수 숲과 산 능선, 구름은 더 바깥으로 밀었습니다.
- 굴러가는 지평선: 카메라에서 멀어질수록 땅이 살짝 아래로 굽어 보입니다(70m에서 멈춰 먼 산은 그대로 보임). 그림자 계산과 하늘에는 적용하지 않습니다.
- 툰 음영: 빛을 3단계로 끊어 칠해 그림책 같은 명암을 냅니다.
- 바람: 풀 1만여 포기와 꽃, 나뭇잎, 덤불이 바람에 살랑입니다.
- 석등·파라솔 전구·포차 전구에 은은한 빛 번짐을 더했습니다.
- 캐릭터: 눈을 깜빡이고, 발밑에 둥근 그림자가 있으며, 달릴 때 발걸음 먼지가 일어납니다. 그림자는 내 캐릭터를 따라다녀 넓어진 곳에서도 생깁니다.


- 기도하기2: 두 손에 오색 종이술을 단 큰 칼을 하나씩 들고, 만세 자세로 팔을 쭉 뻗은 채 제자리에서 계속 뜁니다. 칼은 이 동작 중에만 보이고 비가 와도 우산을 접습니다. 방 서버 자세 목록에 `pray2`를 추가했습니다.
