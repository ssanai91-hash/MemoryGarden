# 기억의 정원 · MemoryGarden

좌불상 앞에서 기도하거나 108배를 하고, 강아지와 산책하는 3D 웹 정원입니다.

## 실행과 기능

정적 웹 서버에서 `index.html`을 엽니다. WebGL 지원 브라우저와 Three.js·Google Fonts CDN 접속이 필요합니다.

- 조이스틱·WASD·방향키·땅 클릭으로 이동, 드래그로 시선 변경, 휠로 거리 조절.
- 사진 업로드·추모 액자를 제거하고 큰 좌불상·연꽃 좌대·기도 마당·방석·등불을 배치했습니다. 동상은 외부 모델 없이 기본 3D 도형으로 구성한 표현입니다.
- 합장 기도·한 배·자동 108배: 버튼을 누르면 중앙 방석으로 이동해 동상을 바라봅니다.
- 1배는 8초입니다. 완료된 절만 횟수에 포함합니다. 잠시 멈춤/이어 하기·마치기·확인 후 초기화를 지원합니다. 이동하거나 다른 자세를 선택하면 중단됩니다.
- 완료 횟수는 이 브라우저에 저장합니다. 새로고침 후에는 자동 재생하지 않으며, 108배 완료 후 초기화해야 다시 시작합니다. 브라우저 저장소를 삭제하면 횟수도 사라집니다.
- 백그라운드 탭에서는 절 진행을 멈춥니다. 명시적 일시정지는 복귀 후에도 유지합니다.
- 낮밤은 기기의 현재 시각을 Asia/Seoul로 환산해 적용합니다. 새벽 05:30~08:00, 저녁 17:00~19:30에 점진적으로 변합니다. 실제 일출·일몰 API는 사용하지 않습니다.
- 날씨는 실제 기상 정보가 아닌 연출입니다. 자동 모드에서 활성 화면 시간 90초마다 맑음→비→눈으로 순환하며 직접 선택할 수도 있습니다.
- 좌불상: 콘셉트 시안 기준으로 다시 만들었습니다. 나발(곱슬 머리 400여 개)·육계·긴 귓불·감은 눈과 미소·선정인 손·가사 선, 2단 연꽃 좌대와 석대, 광배. 도형으로 구성한 모델이며 사진 재구성 GLB는 아닙니다.
- 공간: 동심원 돌 포장 마당, 석등 8기(밤에 불빛), 방석 3개, 연못과 붉은 난간 아치 다리, 둥근 산 능선·침엽수 숲·구름, 덤불·꽃·바위. 나무·덤불·바위는 휴대폰 성능을 위해 인스턴싱으로 그립니다. 세로 화면은 시야각을 넓혀 불상 전체가 보이게 합니다.
- 모닥불 GLB를 HTML에 포함했습니다. 모닥불 보기 버튼으로 이동하고, 불꽃 애니메이션을 재생하거나 멈출 수 있습니다.
- 꽃 놓기·강아지 뽑기·기존 산책 자세를 유지했습니다.
- 커피 마시기 자세: 오른손에 잔을 들고 천천히 한 모금씩 마십니다. 강아지는 옆에 엎드려 기다립니다.
- 함께 듣는 사찰 음악: 새벽 예불·산사의 바람·싱잉볼 명상·고요한 선율 4곡. 외부 음원이 아니라 브라우저가 Web Audio로 실시간 합성하는 오리지널이라 저작권 문제가 없습니다. Claude 아티팩트에서는 편집 권한자가 고른 곡이 `memorial/music` 문서에 기록되고, 모든 접속자가 같은 시작 시각 기준으로 같은 박자를 듣습니다(기기 시계 차이만큼 오차). 각자 '소리 켜기'를 한 번 눌러야 하며 볼륨은 개인 설정입니다. 일반 브라우저에서는 혼자 듣습니다.
- 반야심경 · YouTube: 음악 목록에서 선택하면 영인스님 독송 영상 플레이어가 열립니다. 영상 안의 재생 버튼을 누르고 볼륨·일시정지를 조절합니다. 다른 YouTube 공유 링크를 입력해 바꿀 수 있고, 선택한 영상 ID는 이 브라우저에 저장합니다. 공유 연결에서는 영상 선택만 공유하며 각자의 재생 위치는 동기화하지 않습니다. 다른 곡 선택 또는 플레이어 닫기로 YouTube 재생을 중단합니다. 임베드 재생이 제한된 영상은 YouTube에서 열기로 감상합니다. 음원을 다운로드하거나 저장하지 않습니다.
- 화면 정리: '함께 걷기'와 연결 후 '친구 초대'는 상단에 표시합니다. 날씨·꽃·음악·모닥불·강아지 버튼은 '메뉴 펼치기', 커피·손 흔들기·앉기·눕기는 '동작' 버튼 안에 접혀 있습니다. 기본은 접힘이며, 펼친 상태는 이 브라우저에 기억합니다.
- 이름: 처음 들어오면 정원에서 불릴 이름(12자)을 묻습니다. '나중에'로 넘길 수 있고, 메뉴의 '이름 바꾸기'로 고칩니다. 이 브라우저에 저장합니다.
- 함께 걷기(방 서버): `worker/`의 Cloudflare Worker + Durable Object가 방 하나를 맡습니다. 주소의 `#r-방코드`가 방이고, 처음 연 사람에게 방 코드가 만들어집니다. '친구 초대'로 링크를 공유하면 같은 방에 들어옵니다. 위치·방향·자세·외형·강아지·이름을 실시간으로 주고받고, 꽃·음악 선택·날씨·최근 대화 50개는 방에 저장되어 늦게 온 사람도 같은 상태를 봅니다. 방 정원은 16명입니다. 음악 박자와 자동 날씨 순환은 서버 시각 기준으로 맞춥니다.
- 말하기: 오른쪽 아래 '말하기'로 한마디(200자, 초당 1회)를 보내면 머리 위 말풍선으로 7초간 보이고 대화창에 쌓입니다.
- 횟수 초기화는 `confirm()` 대신 두 번 누르기로 바꿨습니다(Claude 아티팩트 화면은 확인 창을 막습니다).

## 방 서버 배포 (사용자 진행)

정원 화면과 방 서버는 별도 배포입니다. 기존 정원 사이트만 수동 빌드하면 `worker/`의 방 서버가 함께 배포되지는 않습니다. 방 서버는 처음 한 번 아래 순서로 배포합니다. 이 변경은 자동 배포 설정을 만들거나 변경하지 않습니다.

1. 최신 main을 받은 로컬 저장소의 `worker/` 폴더에서 처음이면 `npx wrangler login`으로 Cloudflare 계정을 연결합니다.
2. 같은 폴더에서 `npx wrangler deploy`를 실행합니다. `worker/wrangler.toml`의 방 서버와 Durable Object 구성이 사용됩니다.
3. 배포 후 나온 주소(예: `https://memorygarden-rooms.<계정>.workers.dev`)를 복사합니다. 일반 정원 사이트 주소와 구분하세요.
4. 최신 main으로 정원 사이트도 수동 빌드한 뒤, 정원 상단 **함께 걷기 → 방 서버 주소 붙여 넣기 → 연결하기**를 누릅니다. `https://`와 `wss://` 모두 입력할 수 있으며 브라우저에 저장합니다. 소스 코드를 다시 수정할 필요는 없습니다.
5. 연결되면 **친구 초대**를 눌러 카톡 등에 링크를 보냅니다. 서버 주소와 방 코드가 포함되므로 친구는 링크를 열고 이름만 정하면 됩니다. 상단 인원수·서로의 캐릭터·말하기로 같은 방인지 직접 확인합니다.

공유 기능을 지원하지 않는 브라우저에서는 링크를 복사합니다. 자동 복사가 막히면 연결창에 표시된 링크를 직접 선택해서 복사할 수 있습니다. 친구가 사이트 기본 주소만 별도로 열면 다른 방일 수 있으므로 **같은 초대 링크**를 사용합니다. 내려받은 HTML 파일 대신 배포된 웹주소에서 접속하세요.

서버 연결 전에는 혼자 걷습니다. 연결 실패·재연결 중·정원 가득 참은 상단과 연결창에 표시합니다. 인터넷 복구 또는 화면 복귀 시 연결을 다시 시도하며, 상단 **함께 걷기**에서 주소를 고치거나 **다시 연결**할 수도 있습니다. **연결 끊기**를 누르면 재접속을 중단하고 혼자 걷기로 돌아갑니다.

운영 기본 서버를 고정하려면 기존처럼 `index.html`의 `<meta name="garden-room-server" content="">`에 `wss://…` 주소를 넣어도 됩니다. 초대 링크의 `gardenServer`가 있으면 그 주소를 우선합니다. 정원 사이트 출처만 허용하려면 `worker/wrangler.toml`의 `ALLOWED_ORIGINS`에 정원 사이트의 `https://호스트`를 적고 방 서버를 다시 배포합니다. 경로와 `#r-방코드`는 넣지 않습니다. 서비스 이용 한도는 본인의 Cloudflare 계정에서 확인합니다.

Claude 아티팩트 안에서 열면 Claude의 기존 실시간 기능을 사용합니다(말하기는 말풍선만, 대화 기록은 남지 않음).

## 저장·공유·배포

비공개 소스 저장소입니다. 일반 변경은 **GitHub main에 커밋·반영**합니다. Cloudflare 수동 빌드·배포와 화면 검증은 사용자가 담당하며, 도우미의 Cloudflare 직접 배포는 별도 명시 요청이 있을 때만 진행합니다. GitHub 저장과 Cloudflare 실제 서비스 배포는 별도 단계입니다. 기존 Cloudflare Git 연동 설정에 따라 main 반영이 자동 빌드를 유발할 수 있습니다. 이 변경에서는 배포 설정을 조작하지 않습니다. `AGENTS.md`를 먼저 확인하세요.

방 서버를 연결하지 않은 일반 브라우저에서는 1인 산책이며 횟수·꽃·캐릭터·강아지는 localStorage에 보관합니다. 방 서버를 연결하면 위치·이름·자세 등을 중계하고 꽃·음악·날씨·최근 대화를 같은 방에서 공유합니다. 절 횟수·개인 볼륨은 각 기기 설정입니다. 이전 사진 데이터는 더 이상 읽거나 표시하지 않습니다.
