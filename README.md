# 기억의 정원 · MemoryGarden

좌불상 앞에서 기도하거나 108배를 하고, 강아지와 산책하는 3D 웹 정원입니다.

## 실행과 기능

운영 주소는 https://memorygarden.ajit-worker.workers.dev/ 입니다. 정원 화면과 실시간 서버를 같은 Cloudflare Worker로 배포합니다. `index.html`을 정적 서버에서만 열면 산책 화면은 볼 수 있지만 함께 걷기 연결은 제공되지 않습니다. WebGL 지원 브라우저와 Three.js·Google Fonts CDN 접속이 필요합니다.

- 조이스틱·WASD·방향키·땅 클릭으로 이동, 드래그로 시선 변경, 휠로 거리 조절.
- 사진 업로드·추모 액자를 제거하고 큰 좌불상·연꽃 좌대·기도 마당·방석·등불을 배치했습니다. 동상은 외부 모델 없이 기본 3D 도형으로 구성한 표현입니다.
- 합장 기도·한 배·자동 108배: 버튼을 누르면 중앙 방석으로 이동해 동상을 바라봅니다.
- 1배는 8초입니다. 완료된 절만 횟수에 포함합니다. 잠시 멈춤/이어 하기·마치기·확인 후 초기화를 지원합니다. 이동하거나 다른 자세를 선택하면 중단됩니다.
- 완료 횟수는 이 브라우저에 저장합니다. 새로고침 후에는 자동 재생하지 않으며, 108배 완료 후 초기화해야 다시 시작합니다. 브라우저 저장소를 삭제하면 횟수도 사라집니다.
- 백그라운드 탭에서는 절 진행을 멈춥니다. 명시적 일시정지는 복귀 후에도 유지합니다.
- 낮밤은 연결 중에는 보정된 서버 시각을 Asia/Seoul로 환산해 적용합니다. 새벽 05:30~08:00, 저녁 17:00~19:30에 점진적으로 변합니다. 실제 일출·일몰 API는 사용하지 않습니다.
- 날씨는 실제 기상 정보가 아닌 연출입니다. 자동 모드는 서버 시각 기준 90초마다 맑음·비·눈과 강수 강도를 랜덤으로 고르고, 12초 동안 서서히 전환합니다. 비·눈은 약함·보통·강함에 따라 입자 수·속도·크기가 달라집니다. 별의 수·밝기와 구름 양도 바뀌며, 구름이 짙을수록 별과 달이 흐려집니다. 달은 10분마다 초승달·상현달·보름달·하현달 등 7가지 모양 중 랜덤으로 선택하고 부드럽게 전환합니다.
- 좌불상: 콘셉트 시안 기준으로 다시 만들었습니다. 나발(곱슬 머리 400여 개)·육계·긴 귓불·감은 눈과 미소·선정인 손·가사 선, 2단 연꽃 좌대와 석대, 광배. 도형으로 구성한 모델이며 사진 재구성 GLB는 아닙니다.
- 공간: 동심원 돌 포장 마당, 석등 8기(밤에 불빛), 방석 3개, 연못과 붉은 난간 아치 다리, 둥근 산 능선·침엽수 숲·구름, 덤불·꽃·바위. 나무·덤불·바위는 휴대폰 성능을 위해 인스턴싱으로 그립니다. 세로 화면은 시야각을 넓혀 불상 전체가 보이게 합니다.
- 모닥불 GLB를 HTML에 포함했습니다. 모닥불 보기 버튼으로 이동하고, 불꽃 애니메이션을 재생하거나 멈출 수 있습니다.
- 꽃 놓기·강아지 뽑기·기존 산책 자세를 유지했습니다.
- 커피 마시기 자세: 오른손에 잔을 들고 천천히 한 모금씩 마십니다. 강아지는 옆에 엎드려 기다립니다.
- 화면 정리: 상단에는 **친구 부르기** 버튼 하나를 항상 표시합니다. 날씨·꽃·모닥불·강아지 버튼은 '메뉴 펼치기', 커피·손 흔들기·앉기·눕기는 '동작' 버튼 안에 접혀 있습니다. 기본은 접힘이며, 펼친 상태는 이 브라우저에 기억합니다.
- 이름: 처음 들어오면 정원에서 불릴 이름(12자)을 묻습니다. '나중에'로 넘길 수 있고, 메뉴의 '이름 바꾸기'로 고칩니다. 이 브라우저에 저장합니다.
- 친구 부르기·함께 걷기: 고정 정원 주소 하나로 모두 같은 공간에 자동 연결됩니다. 서버 주소 입력·초대코드·방 선택은 없습니다. 휴대폰에서 **친구 부르기 → 카카오톡 → 대화방 선택**으로 링크를 보냅니다. 공유 기능이 없는 브라우저에서는 같은 주소를 복사하고, 복사 권한이 막히면 주소를 직접 선택할 수 있습니다. 친구가 고정 주소를 직접 열어도 같은 정원입니다. 최대 16명이며 위치·방향·자세·외형·강아지·이름을 중계하고 꽃·날씨·최근 대화 50개를 저장합니다.
- 말하기: 오른쪽 아래 '말하기'로 한마디(200자, 초당 1회)를 보내면 최근 말이 머리 위 말풍선에 남고 대화 기록에 쌓입니다. 긴 글은 생략 없이 자동 줄바꿈하고 말풍선 크기를 맞춥니다.
- 횟수 초기화는 `confirm()` 대신 두 번 누르기로 바꿨습니다(Claude 아티팩트 화면은 확인 창을 막습니다).

## 정원 통합 배포 (사용자 진행)

이제 별도의 방 서버 주소를 입력하거나 `memorygarden-rooms` Worker를 만들 필요가 없습니다. 저장소 루트의 `wrangler.toml`이 `memorygarden` Worker에 정원 HTML·WebSocket·Durable Object를 함께 구성합니다. `.assetsignore`는 공개 파일을 `index.html` 하나로 제한합니다.

Cloudflare의 기존 **memorygarden** 프로젝트에서 최신 main을 기준으로 수동 빌드·배포합니다.

- 저장소 루트 디렉터리: 저장소 최상위(`worker/` 아님)
- 별도 빌드 명령: 필요 없음
- 배포 명령: `npx wrangler deploy`
- 설정 파일: 루트 `wrangler.toml`
- 서비스 주소: https://memorygarden.ajit-worker.workers.dev/

처음 통합 구성을 배포할 때 `GardenRoom` SQLite Durable Object와 `ROOMS` 바인딩이 루트 설정으로 생성됩니다. 기존 Cloudflare 설정에 정적 파일만 업로드하는 별도 명령이 지정돼 있다면 위 배포 명령으로 맞춥니다. 도우미는 Cloudflare 대시보드 설정이나 자동 배포 연결을 변경하지 않습니다.

로컬에서 직접 배포하는 경우에도 저장소 루트에서 `npx wrangler login` 후 `npx wrangler deploy`를 사용합니다. `worker/wrangler.toml`은 과거의 분리형 서버 설정이며 현재 통합 정원의 배포 기준이 아닙니다.

배포 후에는 **정원 열기 → 이름 입력 → 친구 부르기**만 하면 됩니다. 별도의 서버 주소·방 코드·연결 버튼은 없습니다. 이전 초대 링크의 브라우저별 방 코드와 서버 주소는 무시하고 현재 사이트의 같은 정원으로 연결합니다. 친구 접속 여부는 상단 인원수·캐릭터·말하기로 사용자가 직접 확인합니다.

연결이 끊기면 상단 상태가 바뀌고 자동으로 재연결합니다. 친구 부르기는 연결을 기다리는 중에도 사용할 수 있습니다. 이번 변경은 Claude 내부 공유 환경에 의존하지 않고 우리 Cloudflare 환경을 사용합니다.

## 저장·공유·배포

비공개 소스 저장소입니다. 일반 변경은 **GitHub main에 커밋·반영**합니다. Cloudflare 수동 빌드·배포와 화면 검증은 사용자가 담당하며, 도우미의 Cloudflare 직접 배포는 별도 명시 요청이 있을 때만 진행합니다. GitHub 저장과 Cloudflare 실제 서비스 배포는 별도 단계입니다. 기존 Cloudflare Git 연동 설정에 따라 main 반영이 자동 빌드를 유발할 수 있습니다. 이번 변경은 방문자의 서버 주소 입력을 없애기 위해 소스의 루트 통합 Worker 설정을 추가합니다. Cloudflare의 자동 배포 연결·워크플로·대시보드 설정은 변경하지 않습니다. `AGENTS.md`를 먼저 확인하세요.

배포된 정원에 접속하면 같은 출처의 WebSocket에 자동 연결합니다. 위치·이름·자세 등을 중계하고 꽃·날씨·최근 대화를 같은 정원에서 공유합니다. 절 횟수·이름·외형은 각 기기에 보관합니다. 이전 사진 데이터는 더 이상 읽거나 표시하지 않습니다.

## 가운데 모닥불 (1단계)

- 정원 가운데를 큰 모닥불로 바꿨습니다. 불꽃·불티·일렁이는 불빛이 있고, 늘 별과 달이 뜬 밤입니다. 비·눈이 오면 별이 흐려집니다.
- 둘레에 통나무 8개(16자리)를 두었습니다. '둘러앉기'를 누르면 가장 가까운 빈자리에 불을 보고 앉습니다. 앉은 채로 커피·캔맥주를 마실 수 있습니다.
- '장작 넣기': 불 가까이 걸어가 장작을 넣고, 불길이 몇 초간 크게 솟습니다. 함께 걷기 연결 중이면 모두의 화면에 같은 불길과 알림이 뜹니다.
- 합장 기도·절하기·108배는 모닥불 둘레 16자리에서 합니다. 방석은 치웠습니다.
- 불상·연꽃 좌대·방석은 지우지 않고 숨겨 두었습니다. 되돌리려면 `index.html`과 `worker/src/index.js`의 `CENTERPIECE`를 둘 다 `'buddha'`로 바꿉니다(밤 고정도 함께 풀립니다).
- 동작 목록의 `yoga`는 서버에 자리만 만들어 두었습니다.

## 편의점 테이블 (2단계)

- 정원 두 곳(앞 오른쪽, 왼쪽)에 지름 2.7m 큰 원형 테이블과 빨강·흰 줄무늬 파라솔(지름 5m)을 두었습니다. 의자는 테이블마다 4개로 서로 2m 이상 떨어져 있고, 파라솔 아래 전등이 켜집니다. 실제 편의점 상표는 쓰지 않았습니다.
- 말풍선은 가까운 사람부터 화면 안의 빈 위치를 찾아 위·아래·좌우로 배치합니다. 긴 말풍선은 가로·세로를 화면 크기에 맞추고, 화면 가장자리에 걸리지 않도록 이동합니다.
- 테이블이나 모닥불 가까이 가면 화면 아래 '테이블에 앉기'/'모닥불에 앉기' 버튼이 나오고, 앉아 있으면 '일어나기'로 바뀝니다. 동작 메뉴의 '앉기'는 가장 가까운 빈자리에 앉습니다.
- 테이블에 앉으면 위쪽에 음료수·캔맥주·소주·짠! 막대가 나옵니다. '짠!'을 누르면 잔을 들고, 같은 테이블에 앉아 마시던 친구도 함께 잔을 듭니다(방 서버 `cheers` 알림).

## 포장마차 (3단계)

- 모닥불 뒤쪽 나무 아래에 주황 천막 포장마차 '기억 포차'가 있습니다. 비닐 창, 백열전구, 술병 선반, 끓는 냄비와 빨강·파랑 둥근 의자 8개가 있습니다. 상호는 가상입니다.
- 입구 가까이 가면 '포차 들어가기'로 빈 의자에 나란히 앉고, '포차 나오기'로 밖으로 나옵니다. 앉아 있는 동안은 지붕이 반투명해지고 카메라가 바 전체를 내려다봅니다. 강아지는 포차 앞에서 기다립니다.
- 바 안쪽 사장님이 요리하는 동작을 하고, 주문이 들어오면 "네~ ○○ 나갑니다!" 말풍선을 띄웁니다.
- '주문하기': 안주(오뎅탕·닭발·계란말이·골뱅이무침·김치전·떡볶이)와 술·음료(소주·맥주·막걸리·사이다). 서버에서 주문을 확인하면 주문자 자리 앞 바 위에 최근 안주 4개와 최신 술병·잔이 놓입니다. 술을 시키면 그 잔을 들고 마십니다. 결제·가격은 없습니다.
- 주문 내역은 방 서버 `shared.pocha`에 최근 48개까지 남아 늦게 온 친구도 같은 상차림을 봅니다. '상 치우기'로 내 자리를 비웁니다. 포차 안에서 '짠!'은 포차에 앉은 사람끼리 함께 잔을 듭니다.
