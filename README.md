# 기억의 정원 · MemoryGarden

우리 아이를 기억하는 산책길. 추모 정원 산책 웹앱의 원본 소스를 보관하는 비공개 저장소입니다.

## 보관 원본

- `index.html`: 2026-11-01 전달받은 `기억의 정원 (1).html`을 내용 변경 없이 보관했습니다.
- 원본 출처: https://claude.ai/artifact/1jVrtMDkBmhdnuc4RQH4Nd
- Three.js 기반 3D 정원, 조이스틱·WASD·클릭 이동, 강아지, 손 흔들기·앉기·눕기, 꽃 놓기, 추모 사진·이름·함께한 날 입력을 포함합니다.

## 현재 상태

- 이번 작업은 소스 백업입니다. Cloudflare 배포와 자동 배포 설정은 하지 않았습니다.
- 일반 브라우저에서는 추모 사진·이름·날짜·꽃 등을 localStorage에 저장합니다. 브라우저 데이터를 지우면 해당 자료도 사라질 수 있으며, 다른 방문자와 공유되지 않습니다.
- 실시간 함께 걷기와 공유 저장은 Claude 전용 `claude.use('room'/'user'/'db'/'assets')`에 의존합니다. Cloudflare에서 사용하려면 별도 서버 연결이 필요합니다.
- Three.js와 글꼴은 외부 CDN을 사용합니다.
- 사용자 사진과 브라우저 저장 데이터는 이 저장소에 포함되어 있지 않습니다.

소스 변경은 커밋으로 기록하고, 실제 배포는 별도 요청 시 진행합니다.
