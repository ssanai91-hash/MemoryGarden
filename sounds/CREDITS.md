# 자연의 소리 출처

현재 녹음 파일 **0개**. `sounds-src` 릴리스가 아직 없어 녹음 원본을 받지 않았습니다.
이 버전은 직접 생성하는 합성음만 사용하며, 아래 표에 타인의 녹음을 등록한 것처럼 기재하지 않습니다.
폭포·시냇물·호수·빗소리·처마 빗방울·천둥 및 녹음 미제공 효과음은 브라우저에서 합성합니다.

녹음을 받을 때 각 파일의 원본 페이지 URL, 작성자, 파일별 라이선스를 확인해
`tools/prepare_sounds.py`의 sources JSON에 입력합니다. 변환 도구가 이 문서를 실제 사용 파일 목록으로 갱신합니다.
원본은 GitHub `sounds-src` 릴리스에 보관하고 저장소에는 Ogg Opus와 MP3 변환본만 추가합니다.
