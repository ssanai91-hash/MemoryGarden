# 자연의 소리 출처

현재 녹음 파일 **31개** (Ogg Opus 64kbps + MP3 96kbps, 모노).

## 원본
모든 녹음은 오픈소스 앰비언트 앱 **Moodist**(https://github.com/remvze/moodist, 코드 MIT)의 `public/sounds/` 폴더에서 가져왔습니다.
Moodist README의 *Third-Party Assets* 항목에 따르면 이 소리들은 **Pixabay Content License** 또는 **CC0** 중 하나로 제공됩니다.
두 라이선스 모두 출처 표기 없이 사용·수정할 수 있으며, Pixabay는 소리 파일 자체를 단독으로 판매·배포하는 것만 금지합니다.
Moodist는 파일별 원작자·원본 페이지를 따로 밝히지 않으므로, 아래 표에는 Moodist 안의 원본 파일 경로와 사용 구간을 적습니다.

- 반복 소리(`_loop`)는 28초 구간을 잘라 끝과 처음을 1초 겹쳐 끊김 없이 이었고, RMS로 음량을 맞췄습니다.
- 한 번씩 나는 소리는 가장 뚜렷한 지점을 찾아 잘랐습니다(발소리는 발이 닿는 순간 0.04초 앞부터).
- 녹음이 없는 소리(장작 놓기 `log_drop`, 나무·돌 발소리 `step_wood`·`step_stone`, 폭포·시냇물·호수·빗소리·천둥)는 지금처럼 합성합니다.
